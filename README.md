# Palimpsest

A manuscript-style writing archive with layered revisions, marginalia, version comparison and local storage. Built with plain HTML, CSS and JavaScript.

**Live demo:** https://ayo-2010.github.io/palimpsest/

## Features

- Keep multiple folios in a parchment archive
- Every folio holds independent layers, from a base impression to later revisions
- Select any layer to read or edit it
- Add a new revision that starts from the current layer
- Keep margin notes beside the manuscript and remove them individually
- Compare the first layer with the layer you are reading
- Search titles, manuscript text and marginalia
- Word, reading-time and archive-total counts
- Export the current layer as a plain text file
- Everything is saved in localStorage
- Responsive layout down to 390px, reduced motion support and a global `[hidden]` rule

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
